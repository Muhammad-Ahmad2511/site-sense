# Demonstration Script

1. Introduce the light-theme single-page interface and the “evidence first” principle.
2. Enter a public website and start the automatic Whole Website audit.
3. Show the validation and audit progress messages.
4. Explain the score formula and category breakdown.
5. Open one finding and distinguish the collected evidence from the editable recommendation.
6. Filter by accessibility, then by high importance.
7. Show the pages and collected runtime indicators.
8. Edit one recommendation and export the JSON report.
9. Use Print / Save PDF for the human-readable report.
10. Demonstrate an invalid, private, or blocked URL and show that the application reports failure instead of generating findings.
11. When configured, request the optional AI explanation and verify that its priorities reference existing finding IDs.
12. Finish with the limitations and required human review.
